Select listing attributes from values that already exist in the product facts.

Return JSON: {"attributes": [{"key": string, "value": string, "source_fact": string}]}

Rules:
- key must be a template key from the data.
- value must equal a fact already in the product, or a template allowed_value that the seller string matches case-insensitively.
- source_fact is a dotted path into the product, such as attributes.color or attributes.color_name.
- Do not invent material, fabric, certifications, or any value that is not in the facts.
- If a required attribute cannot be filled from facts, omit it.
