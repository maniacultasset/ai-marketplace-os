Write listing copy for this product.

Return JSON: {"title": string, "bullets": [string], "description": string, "claims": [{"text": string, "fact_keys": [string]}]}

Writing rules:
- Title leads with the product type and a fact that is in the data (fabric, colour, or the seller title).
- Do not add "best", "number one", or a certification word unless that fact exists.
- Bullets: one fact each. No bullet that only restates the title. 1 to 10 bullets.
- Description: short paragraphs, no HTML, no marketplace name.
- Stay inside the max lengths given in the data. Avoid banned terms.
- Each claim.text must be a sentence you used, and each fact_keys entry must be a dotted path into the product that actually has a value (for example attributes.color or identity.brand_name).
- If a required fact is missing, omit the sentence. Do not guess cotton because the category is apparel.
