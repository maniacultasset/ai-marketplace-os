# Environment register

The single consolidated list. Local values match `docker-compose.yml` exactly so the bootstrap works on a clean machine. Production values come from Secret Manager, never from a file in git.


## App

| Variable | Local value | Source | Required | Notes |
|---|---|---|---|---|
| `APP_ENV` | `local` | local .env | required | local \| staging \| production. THE single environment switch: admin kill-switch, Sentry environment tag and LocalKmsStub selection all read this. `ENV` is forbidden. |
| `APP_ROLE` | `api` | local .env | optional | api \| worker \| migrate \| seed \| shell; default api (ADR-0013 §1). Picks the boot requirements: api needs DATABASE_URL and JWT_SECRET, worker needs DATABASE_URL, migrate needs ALEMBIC_DATABASE_URL, seed needs DATABASE_URL and ALEMBIC_DATABASE_URL (S9; the seed itself refuses any APP_ENV but local), shell nothing more. The image sets it per role. |
| `APP_NAME` | `marketplace-os-api` | local .env | optional | Worker deployment overrides to marketplace-os-worker. |
| `API_V1_PREFIX` | `/api/v1` | local .env | required | Never change. /healthz, /readyz, /openapi.json, /docs, /internal/admin sit outside it. |
| `LOG_LEVEL` | `INFO` | local .env | optional | DEBUG locally if you want SQL echo context; INFO everywhere else. |
| `LOG_FORMAT` | `console` | local .env | optional | console locally for readability; json in staging/prod (Cloud Run stdout is the transport). |
| `ALLOWED_ORIGINS` | `http://localhost:3000` | local .env | required | Comma-separated. staging: https://app-staging.<domain>; prod: https://app.<domain>. |
| `DASHBOARD_BASE_URL` | `http://localhost:3000` | local .env | optional | The dashboard origin (scheme, host and port only) the OAuth callback redirects to: `{DASHBOARD_BASE_URL}/marketplaces/connected?pending=<handle>` (S15). Staging/prod: the FE's https origin; http or loopback values are refused outside local. |
| `REQUEST_MAX_BODY_BYTES` | `10485760` | local .env | required | 10 MiB hard cap. Cloud Run rejects bodies over 32 MiB; the 50 MB multipart bulk path is forbidden — large CSVs go via signed GCS upload URL. |
| `RATE_LIMIT_PER_TENANT_PER_MIN` | `120` | local .env | required | The 600 figure is deleted. |
| `RATE_LIMIT_PER_IP_PER_MIN` | `60` | local .env | required | Applies to unauthenticated routes. |
| `AUTH_LOGIN_RATE_LIMIT_PER_MIN` | `5` | local .env | required | Per IP + per email on POST /api/v1/auth/login. |
| `AUTH_LOGIN_EMAIL_RATE_LIMIT_PER_MIN` | `10` | local .env | required | Per email from any address on POST /api/v1/auth/login and /signup/status, so rotating addresses cannot multiply the guesses on one account. |
| `OAUTH_STATE_TTL_SECONDS` | `600` | local .env | required | Marketplace OAuth state parameter lifetime (stored in Postgres `oauth_states`). |
| `ADMIN_ENABLED` | `true` | local .env | required | The internal SQLAdmin mounts only when ADMIN_ENABLED=true AND APP_ENV != production. CI test asserts /internal/admin returns 404 with APP_ENV=production. |
| `ADMIN_BASE_URL` | `/internal/admin` | local .env | optional | Unversioned by design. |
| `ADMIN_READ_ONLY` | `true` | local .env | required | Must be `true` in v1; `false` refuses boot (requeue is the staff CLI, `python -m app.cli jobs requeue`). |
| `ADMIN_SESSION_SECRET` | `dev_only_admin_session_secret_at_least_32_chars` | both | required | Secret Manager in staging/prod; 32+ random bytes. |
| `ADMIN_STAFF_EMAILS` | `(empty — leave blank)` | local .env | optional | Comma-separated allowlist, second layer behind IAP/IAM. |
| `ADMIN_LOCAL_EMAIL` | `dev@local` | local .env | optional | Used only when APP_ENV=local. |
| `PORT` | `8000` | local .env | required | 8000 locally (a second worktree sets its own value in its `.env`). Cloud Run injects `$PORT` (image default 8080); the worker health server binds `settings.port`, which is why this is a register row and not a hard-coded constant. |
| `ORIGIN_AUTH` | `off` | local .env | optional | off \| enforce; default off; api only (ADR-0025, proposed). `enforce` answers 403 `PERMISSION_DENIED` to any request outside `/healthz` and `/readyz` that lacks the Cloudflare Worker's `x-kuinn-origin-auth` header, before routing. The header is stripped from every request in both modes; a matched header also lets the app trust the Worker's `x-kuinn-client-ip` for rate limits. `enforce` without a valid `EDGE_ORIGIN_SECRET` refuses boot. |
| `EDGE_ORIGIN_SECRET` | `(empty — leave blank)` | Secret Manager | required by the api when `ORIGIN_AUTH=enforce` | The Worker's origin secret (ADR-0025): one value, or two separated by one space during a rotation (current, then previous). Each value ASCII, no whitespace, 32+ characters, in every APP_ENV; a set value of any other shape refuses the api's boot under `off` too; `deploy.sh` generates 64 hex characters and binds it to the api only. Compared in constant time against every value. Never in a committed file or a log line; in the redaction deny-list (`*_secret`). |
